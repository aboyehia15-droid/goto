# منصة متابعة الحلقات — مجمع ابن تيمية القرآني
جمعية تعلم للقرآن وعلومه (فرع الخبر والدمام)

تطبيق ويب (يُثبَّت على الجوال) لمتابعة الطلاب في القرآن الكريم والقاعدة النورانية وزاد الطفل المسلم، مع صفحة خاصة لكل طالب يفتحها ولي الأمر.

## المحتويات
- `index.html` + `js/` + `css/` — التطبيق
- `data/quran.js` — فهرس الآيات وصفحات مصحف المدينة (604) لحساب الأوجه، ونص جزء عم
- `data/noorania.js` — دروس القاعدة النورانية الـ18 ببنودها
- `data/zad.js` — منهج زاد الطفل (قابل للتعديل من الإعدادات)
- `server/Code.gs` — الخادم (Google Sheets + Apps Script)

## التشغيل
1. افتح التطبيق: https://aboyehia15-droid.github.io/goto/tahfeez/
2. الإعدادات ← الربط بالخادم ← اتبع الخطوات (لصق `server/Code.gs` في Apps Script ونشره).
3. أرسل رابط التسجيل لأولياء الأمور ← فعّل المسجلين ← أضف المعلمين والفصول ← ابدأ المتابعة.

الروابط:
- نموذج التسجيل: `?reg=1`
- صفحة ولي الأمر: `?p=رمز-الطالب`
- شاشة الأوائل: `#/tv`
