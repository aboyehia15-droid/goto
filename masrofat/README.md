# مصروفات مجمع ابن تيمية

برنامج لتسجيل مصروفات المجمع: رفع الفواتير (واحدة أو مجموعة)، قراءتها آلياً وإدخال بياناتها في الكشف مع صورة الفاتورة، واستبعاد المكررة، وإصدار الكشوف بالشعارين.

- **الواجهة:** https://aboyehia15-droid.github.io/masrofat/ (في مستودع masrofat المستقل). هذا المجلد يحوي كود الخادم فقط.
- **البيانات:** جدول جوجل (ورقة «الفواتير» بنفس أعمدة الكشف المعتمد) + مجلد صور الفواتير في Google Drive.
- **التحديث:** أي تعديل يُرفع إلى هذا المجلد يصل تلقائياً (الخادم خلال 10 دقائق، والواجهة عند فتح الصفحة).

## التشغيل لأول مرة (مرة واحدة فقط)

1. أنشئ جدول جوجل جديداً باسم «مصروفات مجمع ابن تيمية».
2. من القائمة: **الإضافات ← Apps Script**. احذف الكود الموجود، والصق محتوى الملف [`server/Loader.gs`](server/Loader.gs) كاملاً، ثم احفظ.
3. اختر الدالة **setup** أعلى المحرر واضغط **تشغيل**، ووافق على الصلاحيات (اضغط «تحديد الكل»).
4. **نشر ← عملية نشر جديدة ← تطبيق ويب**: «تنفيذ باسم: أنا» و«من لديه صلاحية الوصول: أي شخص». انسخ الرابط الذي ينتهي بـ `/exec`.
5. افتح رابط الواجهة أعلاه، وألصق رابط الخادم، ثم أنشئ حساب المدير.
6. من ⚙️ **الإعدادات ← القراءة الآلية** ألصق مفتاح Gemini المجاني من https://aistudio.google.com/apikey

## الملفات

| الملف | ما فيه |
|---|---|
| `index.html` | هيكل الصفحات |
| `styles.css` | الألوان والتنسيق (الألوان الأساسية في أول الملف) |
| `app.js` | عمل الواجهة: الرفع، القائمة، الكشوف، Excel، الإعدادات |
| `config.js` | رابط الخادم والشعاران الافتراضيان |
| `server/Code.js` | الخادم: الأوراق، المستخدمون والصلاحيات، القراءة الآلية، كشف التكرار، السجل |
| `server/Loader.gs` | المُحمِّل الذي يُلصق مرة واحدة في Apps Script |
| `logo-right.png` / `logo-left.jpg` | شعار جمعية تعلّم (يمين) وشعار مجمع ابن تيمية (يسار) |

## عند نسيان كلمة مرور المدير
في محرر Apps Script اختر الدالة **resetAdmin** واضغط تشغيل؛ تظهر كلمة مرور مؤقتة في «سجل التنفيذ».
